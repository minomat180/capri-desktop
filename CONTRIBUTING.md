# Contributing

This fork is a personal project: the Linux and macOS ports are built for one person's setup.
Issues that report a bug in either port are welcome. Pull requests are read, but there is no
promise to merge them.

Changes to Capri herself (her art, lines, animations, the Windows app) belong upstream at
[mochiiwuff/capri-desktop](https://github.com/mochiiwuff/capri-desktop). Keep `src/renderer/` close
to upstream so its changes can still be merged; platform code goes in `linux/` or `macos/`.
